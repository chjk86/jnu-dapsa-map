# 답사 지도 GitHub Pages 배포 안내

## 1. 저장소 만들기 (1회)

1. github.com 로그인 → New repository → 이름 예: `jnu-dapsa-map`, Public
2. 로컬 저장소 연결·업로드:

```bash
cd C:/apps/jnu-dapsa
git remote add origin https://github.com/<계정명>/jnu-dapsa-map.git
git push -u origin main
```

## 2. Pages 켜기 (1회)

1. 저장소 → Settings → Pages
2. Source: "Deploy from a branch", Branch: `main`, 폴더 `/ (root)` → Save
3. 1~2분 후 `https://<계정명>.github.io/jnu-dapsa-map/` 에서 지도 열림

## 3. 실제 데이터 연결 (1회)

`index.html` 상단 `CONFIG`에서 두 값을 교체하고 커밋·푸시:

- `csvUrl`: 구글 시트 "웹에 게시" CSV 주소 (구글폼-체크리스트.md 3절)
- `formUrl`: 구글폼의 "보내기 → 링크" 주소

```bash
cd C:/apps/jnu-dapsa
git add index.html
git commit -m "config: 실제 시트·폼 주소 연결"
git push
```

## 4. 배포 검증

1. 폰에서 Pages 주소 접속 → 지도·마커 표시 확인
2. 테스트 제출 1건 → 약 5분 내 새로고침 시 반영 확인
3. 시트에서 그 행 삭제 → 지도에서 사라지는 것 확인

## 5. POI 좌표 검수 (답사 전 필수)

`poi.json`의 좌표는 근사값이다. 답사 전 각 마커를 구글·네이버 지도와 대조해
어긋난 곳은 `poi.json`의 `lat`/`lng`를 수정하고 커밋·푸시한다.

## 6. 답사 중 운영

- 평상시 할 일 없음 (자동 갱신)
- 부적절한 제출: 시트에서 행 삭제
- '기타' 제출: 시트의 `위도`/`경도` 칸에 좌표 입력 → 지도에 회색 마커로 등장
