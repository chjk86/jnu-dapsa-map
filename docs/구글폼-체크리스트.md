# 답사 제출 구글폼 만들기 체크리스트

지도 페이지는 폼 문항 제목을 CSV 헤더로 읽는다. **문항 제목을 아래와 글자 하나까지 똑같이** 만들 것.

## 1. 폼 문항 (순서대로)

| # | 문항 제목 | 유형 | 설정 |
|---|---|---|---|
| 1 | 팀 | 드롭다운 | `1팀`~`20팀` (팀 편성 확정 후 수정), 필수 |
| 2 | 제출 유형 | 드롭다운 | `답사 기록` / `미션: 말모이` / `미션: 구보` / `미션: 운영전 낭독`, 필수 |
| 3 | 답사지 | 드롭다운 | `poi.json`의 POI 이름 27개를 **그대로** 복사 + 마지막에 `기타(직접 입력)`, 필수 |
| 4 | 기타 장소명 | 단답형 | 선택 (답사지에서 '기타'를 고른 경우만 입력 안내) |
| 5 | 사진 | 파일 업로드 | 최대 5개, 파일당 10MB, 이미지+오디오 허용 (낭독 녹음용) |
| 6 | 내용 | 장문형 | 필수, 안내문: "장소에 대한 해설, 감상, 채집한 낱말, 관찰 단상 등" |

- 파일 업로드 문항을 넣으려면 폼이 구글 계정 로그인을 요구하게 된다 → **학과 공용 계정이 아닌 학생 개인 구글 계정으로 제출**하게 안내 (전남대 구글 계정 가능 여부 확인)
- 설정 → 응답 → "응답 수정 허용" 끄기, "1회로 제한" 끄기 (여러 번 제출해야 함)

## 2. 응답 시트 연결과 열 추가

1. 응답 탭 → 시트 아이콘 → 새 스프레드시트 생성
2. 응답 시트 맨 오른쪽에 열 2개를 직접 추가: `위도`, `경도`
   - '기타(직접 입력)' 제출이 들어오면 운영자가 이 두 칸에 좌표를 입력한다 (구글 지도에서 우클릭 → 좌표 복사)
3. 최종 헤더가 다음과 같은지 확인: `타임스탬프, 팀, 제출 유형, 답사지, 기타 장소명, 사진, 내용, 위도, 경도`

## 3. 시트 웹에 게시 (지도가 읽는 주소)

1. 시트에서 파일 → 공유 → 웹에 게시
2. 게시 대상: 응답 시트 탭 1개만, 형식: **쉼표로 구분된 값(.csv)**
3. "게시" 클릭 후 나온 주소를 복사 → `index.html`의 `CONFIG.csvUrl`에 붙여넣기
4. 게시 주기는 구글이 관리(약 5분). 검수는 시트에서 행 삭제 → 몇 분 내 지도에서도 사라짐

## 4. 사진 폴더 공유 (썸네일 표시용)

1. 드라이브에서 폼 업로드 폴더(폼 이름과 같은 폴더) 우클릭 → 공유
2. "링크가 있는 모든 사용자 — 뷰어"로 변경 (하위 파일에 상속됨)
3. 이 설정을 안 하면 지도에서 사진이 "첨부 파일 열기" 링크로만 보인다

## 5. 개회식 리허설 (1일차 저녁)

1. 전원 테스트 제출 1건씩 (제출 유형 자유)
2. 스크린에 지도를 띄워 실시간 반영 확인
3. 리허설 데이터는 다음 날 아침 운영자가 시트에서 행 삭제로 정리
