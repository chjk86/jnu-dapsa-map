# 답사 제출 구글폼 만들기 체크리스트

지도 페이지는 폼 문항 제목을 CSV 헤더로 읽는다. **문항 제목을 아래와 글자 하나까지 똑같이** 만들 것.

## 1. 폼 문항 (순서대로)

| # | 문항 제목 | 유형 | 설정 |
|---|---|---|---|
| 1 | 팀 | 드롭다운 | `1팀`~`20팀` (팀 편성 확정 후 수정), 필수 |
| 2 | 답사지 | 드롭다운 | `poi.json`의 POI 이름 26개를 **그대로** 복사 + 마지막에 `기타(직접 입력)`, 필수 |
| 3 | 기타 장소명 | 단답형 | 선택 (답사지에서 '기타'를 고른 경우만 입력 안내) |
| 4 | 사진 | 파일 업로드 | 최대 5개, 파일당 10MB, 이미지 허용 |
| 5 | 내용 | 장문형 | 필수, 안내문: "장소에 대한 해설, 감상, 기록하고 싶은 것" |

- 폼 상단 설명에 한 줄 추가: "답사 중에도, 답사가 끝난 뒤에도 사진과 기록을 자유롭게 올려 주세요. 올린 자료는 답사 지도에서 모두가 함께 볼 수 있습니다."
- 파일 업로드 문항을 넣으려면 폼이 구글 계정 로그인을 요구하게 된다 → **학과 공용 계정이 아닌 학생 개인 구글 계정으로 제출**하게 안내 (전남대 구글 계정 가능 여부 확인)
- 설정 → 응답 → "응답 수정 허용" 끄기, "1회로 제한" 끄기 (여러 번 제출해야 함)

## 2. 응답 시트 연결과 열 추가

1. 응답 탭 → 시트 아이콘 → 새 스프레드시트 생성
2. 응답 시트 맨 오른쪽에 열 2개를 직접 추가: `위도`, `경도`
   - '기타(직접 입력)' 제출이 들어오면 운영자가 이 두 칸에 좌표를 입력한다 (구글 지도에서 우클릭 → 좌표 복사)
3. 최종 헤더가 다음과 같은지 확인: `타임스탬프, 팀, 답사지, 기타 장소명, 사진, 내용, 위도, 경도`

## 3. 시트 웹에 게시 (지도가 읽는 주소)

1. 시트에서 파일 → 공유 → 웹에 게시
2. 게시 대상: 응답 시트 탭 1개만, 형식: **쉼표로 구분된 값(.csv)**
3. "게시" 클릭 후 나온 주소를 복사 → `index.html`의 `CONFIG.csvUrl`에 붙여넣기
4. 게시 주기는 구글이 관리(약 5분). 검수는 시트에서 행 삭제 → 몇 분 내 지도에서도 사라짐

## 4. 사진 폴더 공유 (썸네일 표시용)

1. 드라이브에서 폼 업로드 폴더(폼 이름과 같은 폴더) 우클릭 → 공유
2. "링크가 있는 모든 사용자 — 뷰어"로 변경 (하위 파일에 상속됨)
3. 이 설정을 안 하면 지도에서 사진이 "첨부 파일 열기" 링크로만 보인다
- 유의: 시트 게시와 폴더 공유로 제출된 이름·글·사진은 링크를 아는 누구나 볼 수 있게 된다. 폼 안내문에 이 점을 명시할 것.

## 5. 사전 테스트 (운영진만, 출발 전)

별도 오리엔테이션은 하지 않는다 — 학생 사용법은 지도 페이지를 처음 열면 자동으로 뜨는 "안내" 화면이 대신한다. 운영진은 출발 전에 다음만 확인:

1. 운영진 2~3명이 테스트 제출 → 약 5분 뒤 지도에 반영되는지 확인
2. 사진 썸네일이 보이는지 확인 (안 보이면 4번 폴더 공유 설정 재확인)
3. 테스트 데이터는 시트에서 행 삭제로 정리
4. 지도 주소(QR 코드 권장)를 단체 채팅방에 공지 — 학생은 링크만 열면 됨

## 6. 비상 연락처 채우기

`index.html`의 안내 패널(안전·연락 탭)에 있는 비상 연락처 빈칸(`______________`)을 실제 번호로 수정한 뒤 배포할 것.

## 7. 조별 답사지가 정해지면 (선택)

조별 답사지는 학생들이 자유롭게 정하므로 **아무것도 안 해도 시스템은 그대로 작동한다** — 목록에 없는 곳은 '기타(직접 입력)'로 올라오고, 시트의 `위도`/`경도` 칸을 채우면 지도에 핀으로 나타난다.

답사 전에 조별 답사지를 지도에 미리 핀으로 깔아 주고 싶으면:

1. `poi.json`의 `"courses"`에 한 줄 추가 (한 번만):
   ```json
   "team": { "name": "조별 선정 답사지", "color": "#e67e22" },
   ```
2. `"pois"` 배열 끝에 조별 답사지를 추가 — 좌표는 구글 지도에서 해당 장소 우클릭 → 맨 위 숫자 클릭(복사):
   ```json
   { "id": "team01_yunbogo", "name": "윤보선 고택", "lat": 37.5779, "lng": 126.9694, "course": "team", "order": 0, "desc": "3조 선정 답사지." }
   ```
3. 구글폼 '답사지' 드롭다운에 같은 이름을 추가 (글자 단위 동일해야 함)
4. 저장 후 `git push` — 범례에 "조별 선정 답사지" 항목이 자동으로 생긴다
