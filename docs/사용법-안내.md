## 학생용 — 이것만 알면 됩니다

### 1. 접속하기
- 공지된 링크나 QR을 열면 바로 지도가 나옵니다. 설치·가입 필요 없음.
- 앱처럼 쓰려면: 브라우저 메뉴에서 **"홈 화면에 추가"** (카톡에서 열었다면 먼저 "다른 브라우저로 열기").

### 2. 지도 보는 법
- **동그라미 = 답사지.** 누르면 해설과 친구들이 올린 사진·글이 보여요.
- **색 점선 = 권역별 추천 코스** (파랑=서촌, 빨강=창덕궁·종묘, 초록=한글가온길·덕수궁).
- 왼쪽 아래 범례에서 권역을 켜고 끌 수 있어요.
- 상단 **[📖 안내]** 버튼: 사용법·일정·공지·코스·답사지·안전 탭이 모여 있어요.

### 3. 사진·기록 올리기 (가장 중요!)
1. 상단 주황 버튼 **[+ 자료 올리기]** 또는 답사지 팝업의 "이 장소 자료 올리기"
2. 구글 로그인 (아무 구글 계정 OK, 한 번만)
3. 팀 선택 → 답사지 선택(목록에 없는 곳은 **'기타(직접 입력)'** 후 장소 이름) → 사진 최대 5장 → 한 줄 기록 → 제출
4. **5분 안에 지도에 나타나요.** 상단 팀 필터로 우리 팀 것만 모아 볼 수 있어요.
- 💡 **위치 허용**을 켜고 현장에서 올리면 초록 **"현장 인증 ✓"** 배지가 붙어요.
- 💡 답사가 끝난 뒤에도 계속 올릴 수 있어요 (배지만 없음).

### 4. 우리 조 코스 등록하기 (2일차 자율답사 전에!)
- 안내 → **코스 탭** → **[🖊 지도에서 코스 찍기]** → 갈 곳을 순서대로 지도에서 탭 → [✅ 완료] → 팀 고르고 제출. 끝!
- 또는 [✏️ 글로 직접 등록]에서 `수성동 계곡 → 통인시장 → 이상의 집`처럼 화살표(→)로 적어도 돼요. **추천 코스와 상관없이 자유롭게**, 목록에 없는 장소도 OK.
- 등록하면 지도에 **주황 경로선**으로 표시되고, 다시 제출하면 최신 코스로 바뀌어요.

### 5. 공지 확인
- 운영진 공지는 지도 상단 **노란 배너**와 안내의 **공지 탭**에 떠요. 버스 탑승 시간·위치는 **일정 탭** 아래에서.
- ⚠️ 진짜 급한 연락은 단체 채팅방이 1순위예요. 지도 공지는 반영까지 몇 분 걸립니다.

## 운영진용 (조교·학생회장) — 관리는 구글 시트 하나로

관리 시트: https://docs.google.com/spreadsheets/d/1pcgtBpAST2ZiUdl5CF2AbDnF8mn4RXHvbz56AwlzeD4/edit
(편집자로 초대받은 계정으로 접속. 탭 4개가 각각 하나의 기능입니다. 저장하면 **약 5분 안에** 지도에 반영.)

| 시트 탭 | 역할 | 하는 일 |
|---|---|---|
| **설문지 응답 시트1** | 학생 제출물 | 부적절한 제출은 **행 삭제** → 지도에서도 사라짐. '기타' 제출은 맨 오른쪽 `위도`·`경도` 칸에 좌표 입력(구글 지도 우클릭→좌표 복사) → 정확한 위치로 핀 이동 |
| **공지버스** | 긴급 공지·버스 안내 | 행 추가: `유형`에 `공지` → 상단 배너로 / `유형`에 `버스` + 일시·장소 → 일정 탭 표로. 맨 아래 행이 최신 배너 |
| **답사지자료** | 답사지 해설 | `답사지`(지도와 같은 이름) / `해설` / `관련 작품`(줄바꿈·; 구분) / `참고 링크`(`제목 \| 주소`) 작성 → 지도 '답사지' 탭에 표시. 발제조 학생을 편집자로 초대해 직접 쓰게 해도 됨 |
| **조별코스** | 조별 코스 현황 | 자동으로 쌓임. 잘못된 등록만 행 삭제 |

**자주 하는 질문**
- 지도에 안 보여요 → 5분 대기 + 새로고침. '기타' 제출은 좌표 입력 전까지 임시 핀(제출 위치) 또는 목록에만 표시.
- 사진이 링크로만 보여요 → 드라이브의 "제목 없는 설문지 (File responses)" 폴더가 "링크가 있는 모든 사용자-뷰어"인지 확인.
- 폼 문항을 고치고 싶어요 → 폼 편집 권한자가 수정(답사지 목록·팀 수). 문항 '제목'은 절대 바꾸지 말 것(지도가 글자로 매칭).
