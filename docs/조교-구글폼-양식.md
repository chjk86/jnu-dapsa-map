# [조교용] 답사 지도 구글폼 만들기 양식

전남대 국문과 서울·수원 답사(11/5~7) 때 학생들이 사진·기록을 올리는 구글폼을 만드는 양식입니다.
학생이 폼으로 제출하면 답사 지도(https://chjk86.github.io/jnu-dapsa-map/)에 자동으로 표시됩니다.
**문항 제목과 선택지를 아래와 글자 하나까지 똑같이** 만들어 주세요 — 지도가 이 글자를 그대로 읽습니다.
소요 시간 약 15분. 조교 선생님 구글 계정으로 진행하면 그분이 관리자가 됩니다.

---

## 1. 새 폼 만들기

- forms.google.com → 새 양식
- 제목: `전남대 국문과 답사 자료 올리기`
- 설명: `답사 중에도, 답사가 끝난 뒤에도 사진과 기록을 자유롭게 올려 주세요. 올린 자료는 답사 지도에서 모두가 함께 볼 수 있습니다.`

## 2. 문항 5개 (순서·제목·유형을 정확히)

### 문항 1 — 팀
- 유형: **드롭다운**, 필수
- 선택지: `1팀` ~ `20팀` (조 편성이 다르면 실제 조 이름으로 — 단, 한 번 정하면 바꾸지 말 것)

### 문항 2 — 답사지
- 유형: **드롭다운**, 필수
- 선택지: 아래 27줄을 복사한 뒤, 폼의 "옵션 1" 칸을 클릭하고 **한 번에 붙여넣기** 하면 자동으로 나뉘어 들어갑니다.

### 문항 3 — 기타 장소명
- 유형: **단답형**, 선택(필수 아님)
- 설명: `답사지에서 '기타(직접 입력)'를 골랐다면 장소 이름을 적어 주세요.`

### 문항 4 — 사진
- 유형: **파일 업로드** (최대 파일 수 5, 파일당 최대 10MB, 이미지 허용)
- ※ 파일 업로드 문항을 추가하면 "응답자가 구글에 로그인해야 합니다" 안내가 뜹니다 → 확인 누르면 됩니다.

### 문항 5 — 내용
- 유형: **장문형**, 필수
- 설명: `장소에 대한 해설, 감상, 기록하고 싶은 것을 적어 주세요.`

## 3. 폼 설정 (오른쪽 위 '설정' 탭)

- 응답 → "응답 횟수 1회로 제한" **끄기** (여러 번 제출해야 함)
- 응답 → "응답 수정 허용" 끄기

## 4. 응답 시트 연결

1. 폼의 "응답" 탭 → 초록 시트 아이콘 → **새 스프레드시트 만들기**
2. 만들어진 시트를 열고, 맨 오른쪽에 열 2개를 직접 추가: 1행에 `위도`, `경도` 입력
3. 1행이 다음 순서인지 확인: `타임스탬프, 팀, 답사지, 기타 장소명, 사진, 내용, 위도, 경도`

## 5. 공지버스 탭 만들기 (긴급 공지·버스 안내용)

1. 같은 스프레드시트에서 아래 **+** 로 새 시트 탭 추가, 이름을 `공지버스`로 변경
2. 1행에 헤더 4개: `유형`, `일시`, `내용`, `장소`
3. 사용법 (답사 중 조교가 직접 행 추가):
   - 공지: 유형 칸에 `공지`, 내용 칸에 공지문 → 학생 지도 화면 상단에 노란 배너로 표시 (맨 아래 행이 최신)
   - 버스: 유형 칸에 `버스`, 일시에 `11/6(금) 17:30`, 장소에 `경복궁 주차장(사직로 161)`, 내용에 비고 → 지도의 '버스 탑승 안내' 표에 표시
   - 반영까지 약 5분 + 학생이 새로고침해야 보임. **진짜 긴급 상황은 단체 채팅방이 1순위**, 지도는 보조 수단.

## 6. 시트 "웹에 게시" — 주소 2개 만들기

1. 시트에서 **파일 → 공유 → 웹에 게시**
2. 첫 번째: 게시 대상에서 **설문지 응답 탭** 선택, 형식 **쉼표로 구분된 값(.csv)** → 게시 → 나온 주소 복사 = **㉮ 응답 CSV 주소**
3. 두 번째: 같은 창에서 게시 대상을 **공지버스 탭**으로 바꾸고 .csv로 다시 게시 → 주소 복사 = **㉯ 공지버스 CSV 주소**

## 7. 사진 폴더 공유 (지도에서 사진이 보이게)

1. 구글 드라이브에서 폼 이름과 같은 폴더(업로드 폴더)를 우클릭 → 공유
2. "링크가 있는 모든 사용자 — **뷰어**"로 변경
3. ※ 이 설정으로 제출된 글·사진은 링크를 아는 누구나 볼 수 있게 됩니다. 폼 설명에 이미 안내 문구가 있으니 그대로 두면 됩니다.

## 8. 완료 후 보낼 것 — 주소 3개

아래 3개를 복사해서 보내 주세요. 받아서 지도에 연결합니다.

1. **폼 링크**: 폼에서 "보내기" → 링크 아이콘 → 주소 복사
2. **㉮ 응답 CSV 주소** (6-2에서 복사한 것)
3. **㉯ 공지버스 CSV 주소** (6-3에서 복사한 것)
