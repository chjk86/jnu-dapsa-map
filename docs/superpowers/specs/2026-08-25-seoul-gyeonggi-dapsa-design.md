# 전남대 국어국문학과 서울·경기 답사 — 일정 및 답사 지도 설계서

- 작성일: 2026-08-25
- 상태: 승인 대기 (사용자 검토 단계)

## 1. 개요

전남대학교 국어국문학과 2박 3일 서울·경기 답사(2026년 11월, 인원 100여 명, 숙소 도봉산 권역)의 일정안과, 학생들이 답사 자료(사진·글)를 자유롭게 올리고 실시간으로 공유해서 보는 **웹 답사 지도**의 설계.

최종 결과물은 **웹 답사 지도 한 장**이다. 답사 기간 중 실시간 공유 도구이자, 답사 후 학과 아카이브로 남는다.

## 4. 답사 지도 시스템 설계

### 4.1 아키텍처

서버·데이터베이스·로그인 없음. 구성 요소 4개, 각각 독립적.

```
학생 폰 ──구글폼 제출──▶ 응답 시트(구글) ──웹에 게시(CSV)──▶ 지도 페이지(GitHub Pages)
              │                                                    ▲
              └─ 사진 → 구글 드라이브(링크 공개 폴더) ── 썸네일 URL ──┘
```

### 4.2 구성 요소

**① POI(답사지) 목록 데이터** — 사전 등록 답사지 30곳 내외. 항목: 이름, 좌표(위도·경도), 전공 축, 한 줄 해설, 소속 코스. 지도의 뼈대이자 구글폼 드롭다운의 원천. JSON 파일 하나로 관리한다.

**② 구글폼** — 문항: 팀 선택(드롭다운), 제출 유형(답사 기록 / 말모이 낱말 채집), 답사지 선택(POI 드롭다운 + "기타: 직접 입력"), 사진 업로드(복수), 답사기·해설 텍스트. 말모이 제출은 지도에서 별도 마커 색으로 구분해 표시한다. 학생에게 좌표를 입력시키지 않는다 — 위치는 드롭다운 선택으로 해결하고, "기타" 제출은 운영자가 시트에서 좌표를 채우면 지도에 나타난다.

**③ 응답 시트** — 구글 시트를 "웹에 게시"(CSV)로 열어 둔다. 검수는 시트에서 행 삭제로 수행하며, 몇 분 내 지도에서도 사라진다. 사진 업로드 폴더는 "링크가 있는 모든 사용자 보기 가능"으로 1회 설정.

**④ 지도 페이지** — HTML 한 장, Leaflet + OpenStreetMap 타일, GitHub Pages 호스팅. 기능:

- 열릴 때마다 게시 CSV를 읽어 마커 렌더링 (제출 → 반영 지연은 구글 게시 주기 약 5분)
- POI 마커 클릭 → 그 장소의 사진·글을 팀 이름과 함께 카드로 표시
- 전공 축(고전·현대·국어학) 및 팀별 필터
- 자율답사 추천 코스 3종 경로선 표시
- 지도 안에 구글폼 바로가기(제출 버튼) 배치
- **모바일 우선 UI** — 학생들은 현장에서 폰으로 사용

### 4.3 데이터 흐름

학생 폼 제출 → 응답 시트 자동 기록 → 게시 CSV 갱신(약 5분 주기) → 지도 페이지 새로고침 시 반영. 답사 기간 중 운영자 개입은 검수(행 삭제)와 "기타" 위치 보정뿐이다.

### 4.4 오류 처리

- CSV 로드 실패: "잠시 후 다시 시도" 안내, 마지막 성공 데이터 유지
- 사진 로드 실패: 자리 표시 이미지로 대체
- POI 목록과 매칭되지 않는 제출: 지도 하단 "위치 미확정" 목록에 표시해 유실 방지

### 4.5 검증 계획

1. 더미 제출 20건으로 폼→시트→지도 전체 흐름 통과 확인
2. 실제 휴대폰에서 사진 표시·필터·팝업 동작 육안 확인 (모바일 검증)
3. 1일차 저녁 오리엔테이션의 전원 테스트 제출이 실전 부하 리허설을 겸함

### 4.6 운영자 준비 사항

1. 구글폼·응답 시트 생성 (문항 구성·설정 체크리스트 제공 예정)
2. 사진 업로드 드라이브 폴더 공유 설정
3. GitHub Pages 저장소 개설 (안내 제공 예정)
4. POI 목록 30곳 확정 (초안 제공 예정)

## 5. 구현 산출물 목록

1. `poi.json` — 답사지 목록 데이터 (코스 3종 + 공통 답사지 포함 초안)
